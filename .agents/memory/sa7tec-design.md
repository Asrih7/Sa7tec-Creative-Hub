---
name: SA7TEC Design System
description: Core visual identity decisions for the SA7TEC public website — what it must feel like and what to avoid
---

The public site is a cinematic product universe, NOT an agency portfolio.

**Why:** User explicitly rejected: portfolio sections, services grids, testimonials, corporate layout, classic Hero→Services→Portfolio flow.

**Design language:**
- Background: #000 (pure black)
- Accent: #22d3ee (electric cyan) — primary
- Secondary: #a78bfa (violet), #34d399 (green), #fbbf24, #f472b6
- Typography: 'Outfit' 900 weight for display, ui-monospace for labels/data
- Dim text: rgba(255,255,255,0.35-0.4)
- Borders/lines: rgba(255,255,255,0.06-0.1)
- Dot grid: radial-gradient 1px dots, 36px spacing, masked radial fade

**Scene structure (Home):**
1. Entry — 100vh, giant "SA7TEC" letter-by-letter, dot grid, central glow
2. Manifesto — "Not a studio. A signal." kinetic text reveal
3. Product Universe — 5 floating product orbs (NOT a services list)
4. Game Reveal — Rubik's Race with CSS phone mockup, perspective tilt
5. Capabilities — grid command interface (NOT "what we offer" cards)
6. Numbers — HUD stat counters, count-up animation
7. Transmission — CTA "Got an idea? Let's build." + socials + copyright

**How to apply:** Any new public section must introduce a new visual mechanic + new atmosphere. No headers like "Our Services" or "Our Work". Scene labels use monospace: "01 — WHAT WE ARE".
